# Security

## Reporting

Report a vulnerability privately through
[GitHub security advisories](https://github.com/brianhliou/mistboard/security/advisories/new),
or ask for a private channel at [mistboard.com/contact](https://mistboard.com/contact)
without including the details. Please do not open a public issue.

## In scope

- mistboard.com and its API
- Accounts, sign-in and sessions
- Data exposure, including game information a player or engine should not see
- Game integrity: moves, clocks, results and ratings
- Availability of live games

Fixes go to `main` and the live site. We acknowledge reports, fix them, and
credit the reporter on request.
