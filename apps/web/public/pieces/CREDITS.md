# Piece-set credits

SVG assets in this directory are sourced from the lichess [lila](https://github.com/lichess-org/lila/tree/master/public/piece) repository (see lila's `COPYING.md` for canonical license details).

Mistboard is AGPLv3; the sets included here were chosen so every option is license-compatible with that and with future commercial use. Non-commercial (CC BY-NC-SA) sets are intentionally excluded.

The default piece set is **Cburnett**, which ships embedded in `chessground/assets/chessground.cburnett.css` and is not stored as files here. It is listed below for attribution completeness.

| Merida | Armando Hernandez Marroquin | GPLv2+ |
| Chessnut | Alexis Luengas | Apache 2.0 |
| Fantasy | Maurizio Monge | MIT |
| Letter | usolando | AGPLv3+ |

These are the chess sets only. Xiangqi, Jungle and the unused shogi art live in `../piece-sets/`, credited in [`../piece-sets/CREDITS.md`](../piece-sets/CREDITS.md).
